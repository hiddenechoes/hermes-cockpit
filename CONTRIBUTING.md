# Contributing

Thanks for helping improve Hermes cockpit.

## Workflow

1. Open an issue or describe the change clearly in a pull request.
2. Keep changes small and focused.
3. Add tests or verification steps when implementation starts.
4. Update docs when behavior changes.

## Local setup

This repository is currently a scaffold. Add the project dependencies and commands once the implementation stack is chosen.

## Code review expectations

- Prefer simple, incremental changes.
- Avoid unrelated refactors in the same PR.
- Document any assumptions in the PR description.
